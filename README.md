# DSH app (Android)

Тонкая Android-обёртка для облачного [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web GUI:
тот же интерфейс, что в браузере, но отдельным приложением — без адресной строки и вкладок Chrome.

- Первый запуск: логин и пароль basic auth (адрес сервера спрятан в «⋯»).
- Дальше вход автоматический: DSH ставит свою cookie, живёт 30 дней.
- Тонкая панель сверху: `⟳` перезагрузить (долгое нажатие — проверить обновления), `⋯` — настройки входа.
- Системная «назад» — история внутри DSH; внешние ссылки — в браузер с подтверждением; скачивания — в «Загрузки».
- Обновления — из этого репозитория: приложение спрашивает GitHub Releases и предлагает установить новую версию.

## Сборка

```powershell
# JDK 17 + Android SDK 35 + Gradle 8.13
powershell -ExecutionPolicy Bypass -File tools/build.ps1 apk
# APK: app/build/outputs/apk/prod/app-prod.apk
```

Подпись — свой `keystore.jks` в корне проекта (в репозиторий не попадает).

## Установка

Скачай APK из последнего релиза на телефоне и установи (Android спросит разрешение на установку из этого источника).
Обновления ставятся поверх: настройки входа и cookie сохраняются.

## Зависимости

`androidx.appcompat`, `material`, `core-ktx` — всё, больше ничего. Интерфейс — WebView.
